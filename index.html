Leitura de escalas por foto

Cole aqui sua chave de API da Anthropic (criada em console.anthropic.com). Ela fica salva só neste navegador (localStorage), nunca é enviada a mim nem a mais ninguém além da própria Anthropic — é usada apenas para ler suas fotos de escala. Cada leitura custa poucos centavos, cobrados diretamente na sua conta Anthropic.

Sincronizar entre dispositivos

Guarda seus plantões dentro do seu próprio repositório do GitHub (), assim o mesmo dado aparece no computador e no celular. Crie um token em github.com/settings/personal-access-tokens/new: marque "Only select repositories" → escolha este repositório → em "Repository permissions" defina Contents: Read and write → gere e cole abaixo. O token fica salvo só neste navegador.

Sincronizar com o Google Calendário

Cada plantão salvo (ou apagado) é enviado direto para o seu Google Agenda, em tempo real. Configuração única, feita por você em console.cloud.google.com:

  1. Crie um projeto (qualquer nome) e ative a "Google Calendar API" (menu "APIs e serviços" → "Ativar APIs e serviços").
  2. Em "Tela de permissão OAuth", escolha "Externo", preencha o básico e adicione seu e-mail do Google em "Usuários de teste".
  3. Em "Credenciais" → "Criar credenciais" → "ID do cliente OAuth" → tipo "Aplicativo da Web". Em "Origens JavaScript autorizadas" adicione exatamente: https://lucasebsantos4.github.io
  4. Copie o "ID do cliente" (termina em .apps.googleusercontent.com) e cole abaixo.

Na primeira conexão o Google avisa "app não verificado" — é esperado para um app pessoal; clique em "Avançado" → "Acessar (nome do app) (não seguro)" para continuar.

Senha do app

A mesma senha que você digita para abrir o app cifra sua chave da Anthropic e seu token do GitHub automaticamente — eles viajam junto com seus dados para outros aparelhos, sem colar de novo em nenhum campo. A senha nunca é salva em nenhum lugar (nem aqui, nem no repositório); só uma versão cifrada com ela fica no seu repositório, junto dos plantões. O ID do cliente do Google Calendário não é secreto e já sincroniza sozinho.
